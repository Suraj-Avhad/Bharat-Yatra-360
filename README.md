
# Bharat Yatra 360 – Holiday & Travel Organiser

A full-stack travel planning platform built using React, Bootstrap, Spring Boot, Java, and MySQL.
This project helps users explore destinations, book tours, manage itineraries, and view detailed travel information—all from a clean and user-friendly interface.


## Admin Features

- Add, update, delete tours (Full CRUD functionality)
- Manage guides, destinations, and packages
- View all bookings and customer details
- Access Admin Dashboard
- Secure login using JWT Authentication
- API documentation visible via Swagger UI
- Manage images, prices, descriptions
- Approve or reject travel packages

## User Features

- Register & login securely (JWT-based login)
- Browse all tours and destinations
- View detailed itinerary & pricing
- Book guided tours easily
- Manage profile & view booking history
- User-friendly interface for smooth navigation

## Customer Features (Public Features)

- Explore India’s travel destinations
- View images, descriptions, and tour highlights
- Check available packages
- Contact or send enquiry for any tour
- Watch tour videos and review galleries
- Responsive design for mobile & tablet
